# Lurk

Landing site for the Lurk real-time listings API (Vinted, Wallapop, Milanuncios, Todocolección).

```sh
npm install
npm run dev     # localhost:4321
npm run build   # static output in dist/
```

- Domain, WebSocket endpoint, contact email, plans and prices: `src/config.ts`
- All copy (es/en): `src/i18n.ts`
- Example payloads and code snippets: `src/examples.ts`
